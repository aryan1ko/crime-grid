PALANTIR / DATA ENGINEERING INTERVIEW PREP
Project: Austin Crime Ontology & Socioeconomic Analysis

1. THE "DATA QUALITY" QUESTION
Q: "I noticed your logs showed missing coordinates. How did you handle incomplete data?"
A: "The raw Socrata feed had null geometry for several thousand rows. I implemented a 'Spatial Backfill' strategy. I mapped incidents to District and Census Tract IDs first, then used the geometric centroids of those boundaries to approximate the incident location so we didn't lose the data for aggregate analysis."

2. THE "ONTOLOGY" QUESTION
Q: "Why use an Ontology instead of just one big flat CSV table?"
A: "A flat table is a snapshot; an ontology is a system. By separating 'Incidents', 'Locations', and 'OffenseTypes', we can update demographic data (Census) or boundary data (APD Districts) independently without re-processing 500k crime rows. It also allows for 'Entity Resolution'—merging duplicate locations into a single object."

3. THE "SCALABILITY" QUESTION
Q: "How does this pipeline handle 500,000 rows efficiently?"
A: "I used DuckDB as the analytical engine. It’s a columnar database, which is significantly faster than SQLite for the types of JOINs and aggregations used in the stage 3 analysis. It allows the entire pipeline to run in under 20 seconds on a standard MacBook Pro."

4. THE "INSIGHTS" QUESTION
Q: "What was the most surprising thing you found in the Austin data?"
A: "The 'COVID Drift.' While some crimes stayed flat, Motor Vehicle Theft (UCR 240) spiked by 200% between 2019 and 2021. Additionally, Census Tract 11.01 showed a crime rate that was statistically impossible for its resident population, highlighting the 'Workday Population' effect in Downtown Austin."

5. THE "ETHICS" QUESTION
Q: "How did you handle the sensitivity of exact crime locations?"
A: "I normalized addresses and utilized 'Point Jittering' logic in the mapping stage (via Census Tract centroids) to ensure that while we can see hotspots, we aren't creating a tool that can be used to target specific private residences."
